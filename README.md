# 전담 배정 계산기

초등학교 교과전담 시간표를 짜기 전에, 어떤 과목을 몇 시간 전담에게 줄지와
누가 어느 학년 몇 학급을 맡을지를 함께 정해 서로 다른 안 5가지를 보여 주는 계산기입니다.

- 사용: https://echoeun-glitch.github.io/jeondam-calculator/
- 파일 하나(`index.html`)로 되어 있고, 계산은 여는 사람의 브라우저에서 합니다.
- 입력값은 각자 브라우저에만 저장됩니다.

## 지키는 조건

- 전담 교사 시수는 담임 평균과 같거나 최대 2시간 많게 (부장은 감경만큼 예외)
- 담임 시수는 6학년 ≤ 5학년 ≤ 4학년 ≤ 3학년 ≤ 1학년 = 2학년
- 교사·담임 모두 1·2학기 시수 차이는 3시간까지
- 맡는 반은 1년 내내 같음
- 보건은 `학기별로 다르게`를 체크해 1·2학기 시수를 따로 넣을 수 있음 (예: 5학년 2학기만 주당 1시간)
- 보건은 보건교사만 맡고, 보건교사는 시수 범위·학기 간 차이를 따지지 않음

## 미세 조정

- 처음 미세 조정 화면에 들어가면 `사용법 보기`가 강조되고, 누르면 10단계 안내가 나옴 (1단계에서 건너뛰기 가능)
